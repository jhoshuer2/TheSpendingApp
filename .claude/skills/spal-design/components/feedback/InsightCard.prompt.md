Inline insight — daily nudges, tips, celebrations, with an optional trailing metric.

```jsx
<InsightCard variant="celebration" icon={<Icon name="trending-up" size={18}/>} title="Best Tuesday yet" message="You made more than any Tuesday this month." metric="+18%" />
```

- `default` white · `tip` mist · `warning` ochre wash · `celebration` night horizon (the only dark insight).
- Icons sit in a 32px tile. Copy encourages, never shames.
