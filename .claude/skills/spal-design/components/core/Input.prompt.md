Text field — hairline ring, green focus ring; `large` is the hero amount field.

```jsx
<Input label="How much?" large prefix="₦" placeholder="0" inputMode="decimal" />
<Input label="What was it for?" placeholder="e.g. Suya, drinks" />
```

- Labels are 13px secondary, sentence case — never uppercase.
- `large`: 76px tall, 36px medium figures, quiet raised ₦ prefix (mirrors `Money`).
